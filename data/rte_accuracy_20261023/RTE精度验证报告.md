# RTE精度验证报告（2026-10-23）

现有实测全部静止，且无外部相对位置/航向真值。实测结论仅限数据与回放诊断；仿真数据有独立真值。仿真无噪声局部运动输入由仿真轨迹直接生成，用于隔离RTE相对变换求解，不是盒端实际传感器输出；工程中可选雷达里程计前端未用于本次结果。

## 结论

默认RTE实现尚不能据此宣称动态精度已达标。多个随机种子存在米级错误解，READY与小测距残差不保证正确位置。现有3项RTE自检检查功能与选定轨迹，不能覆盖本次更宽的精度试验。

## 复现

从项目根目录执行；现有build_rte_verify是本次使用的独立RTE构建目录。新环境先用cmake -S . -B build_rte_verify -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DZJU_COOP_BUILD_RTE=ON配置。

```bash
cmake --build build_rte_verify --target zju_coop zju_coop_rte zju_coop_rte_self_check zju_coop_three_rte_self_check c_header_smoke_rte -j2
c++ -std=c++17 -O2 -I include tools/evaluate_rte.cpp -L build_rte_verify -Wl,-rpath,"$PWD/build_rte_verify" -lzju_coop_rte -lzju_coop -o build_rte_verify/evaluate_rte
source /opt/ros/humble/setup.bash
source install/ros2-uwb-online/setup.bash
python3 -u tools/evaluate_rte.py
ctest --test-dir build_rte_verify --output-on-failure -R rte
```

主要结果看summary.json、sim_*_output.csv、joint_time_*_output.csv和配套报告figures/07、08、09。输入CSV是机器接口格式，中文全量汇总另存为RTE仿真精度汇总.csv。离线适配将接收时刻置为当前Header时刻以隔离算法数值，不模拟真实网络延迟、ROS调度或硬件授时误差；不是实盒端到端时效验收。
