# V1.4报告理解核对问题

建议先不看正文，逐项用自己的话回答，并指出对应表格或图片。对不上数据的地方记录下来。

1. 本项目现有默认输出是什么，使用哪种传感器，坐标轴如何定义？

3. VIO和LIO各自用了什么设备？本轮输入是图像/点云还是局部位姿输出？
4. IMU白噪声、残余零偏分别怎样进入位置传播，为什么二者影响不同？
5. 起点标定与运动中持续测距的固定锚点有什么区别？仅给一个位置点能否确定方向？
6. 场地坐标的原点、X/Y/Z轴是什么？相对位置由哪个向量减哪个向量？
7. 5厘米测距下，同一IMU输入从起点传播、加入车间UWB、加入3锚点后误差各是多少？
8. 增加相机、雷达或固定锚点分别增加哪些硬件或处理工作？没有报价时如何比较投入？
9. RTE组与起点已经标定的融合组，已知条件和计算方法有什么不同？
10. 图14的三幅图各表示什么、单位是什么？294.48秒发生了什么？
11. 为什么1.7厘米的测距拟合残差会与2米级位置误差同时出现？

13. 纯UWB队形误差、固定场地相对误差和场地绝对误差，三者是否同一指标？
14. 3锚点与4锚点怎样选择？本轮测量噪声、锚点坐标误差和最大基站距离是多少？
15. 起点方向从0.2度变为3度、IMU偏置从0.001变为0.01米/秒²，各改变了哪组结果？
16. 本轮哪些是仿真结果、哪些来自静止实测，亚米级目标下一步如何用实车真值验证？
17. 三锚点逐链路10赫兹为什么对应每秒120条测距？降至1或5赫兹后如何比较？
