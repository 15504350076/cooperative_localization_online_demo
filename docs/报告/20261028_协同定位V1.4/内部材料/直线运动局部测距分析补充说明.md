# 直线运动局部测距分析补充说明

此文件供内部查阅，解释之前报告表格中的“无锚点共6项”和“单锚点共8项”。分析以201车初始局部坐标轴为参考，假设各车局部位移准确，以40秒作为分析起点，考察40～300秒的连续测距能否区分下列起点位置和方向的微小变化。

无锚点时的6个量是：

1. 202车相对201车的初始X位置；
2. 202车相对201车的初始Y位置；
3. 203车相对201车的初始X位置；
4. 203车相对201车的初始Y位置；
5. 202车局部里程计坐标轴相对201参考轴的转角；
6. 203车局部里程计坐标轴相对201参考轴的转角。

单锚点时，在上述6个量之外，还考虑40秒时201车相对锚点的X、Y位置，因此共8个量。这里的两个转角是局部位移坐标轴之间的方向关系，不是额外测得的方位角。201的初始局部轴被选为参考轴，不再把它相对于自身的转角作为未知量。

| 运动方式 | 无锚点：可在局部区分的数量 | 单锚点：可在局部区分的数量 |
|---|---|---|
| 同速平行直行 | 5/6 | 8/8 |
| 不同速平行直行 | 5/6 | 8/8 |
| 非平行直行 | 6/6 | 8/8 |

这些数量通过对仿真真值附近的距离变化求局部敏感度得到；时间段每秒取样，位置和转角按固定尺度归一化后检查数值秩。5/6表示6个量的某一种组合在该模型下无法通过局部微小变化区分，并不表示某一具体坐标或某一辆车的某项测量无效。单锚点的8/8与无锚点的6/6对应不同的未知量集合，不能直接用比值表示精度改善。

局部可区分不等于全局唯一：离真值较远的镜像队形仍可能有相近的测距结果。实际定位试验使用带误差的运动及距离输入，结果保存在data/straight_maneuvers_20261102/；完整设置与重算命令见阅读与复现说明。上述局部分析不是对IMU偏置、动态姿态等所有状态的完整可观性证明。
