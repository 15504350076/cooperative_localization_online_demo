# 报告改动前后对照记录

本文件用于记录阶段报告、测试报告和方案文件的每次修改。后续每次改动完成后，先在本文件追加一条记录，再生成 Markdown、Word、PDF和材料包。记录以“文件路径＋章节或代码锚点＋改动前内容＋改动后内容＋修改原因”的格式填写，保证手工复核时能够定位原文。

## 使用规则

1. 改动前先保存原始版本，或从上一版报告、Git提交和历史归档中提取原文。
2. 位置至少写到文件路径和章节、表格、图片或代码函数；能够确定行号时同时写行号。
3. 改动前、改动后均保留能够识别的完整句子、表格行或代码片段，不用“优化措辞”“完善内容”等笼统描述代替。
4. 同一批次的连续小改动可以合并记录，但必须列出所有受影响文件。
5. 生成 Word、PDF或压缩包后，在记录末尾填写生成命令和验证结果。
