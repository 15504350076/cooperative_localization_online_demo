# SVG修改说明

SVG是矢量文件格式。本报告新数据图中的文字、折线、坐标轴均作为独立对象保存，可用Inkscape编辑；PNG是像素图片。

1. 用Inkscape打开figures下需要修改的.svg，先另存一个副本。
2. 按T选择文字工具，点击标题、图例或坐标文字，修改内容、字号、字体。电脑需安装对应中文字体。
3. 使用选择工具（F1或S）选中对象，移动或缩放；对象在组内时，双击进入组，或按Ctrl+Enter进入。
4. 保存为SVG保留可编辑对象；需要嵌入Word时，可导出高清PNG或PDF。正式结果曲线的数值应通过修改脚本并重算更新，排版微调不改变数据点。

若文字已被转换成轮廓，只能修改轮廓，不能像文本一样改字；若SVG内部只是嵌入一张PNG，仍不能逐个修改图片里的文字和框线。可查看文件是否包含`<text>`标签来辅助判断文字是否保留。

## 当前图1

当前图1直接使用用户提供的五框PNG：figures/图1_协同定位系统组成.png，并按原字节保存在figures/原始素材。生成报告时不重画、不改字、不裁剪、不转码。PNG本身不能逐对象编辑。

目录内早期“图1_协同定位系统组成_可编辑.svg/pptx”为旧版六框图，不是本次PNG的原始可编辑稿。若以后修改当前图1，应在其原始制图软件中修改后重新导出，或提供对应的SVG/PPTX原稿；不能把PNG套一个SVG外壳称为可编辑原稿。

Inkscape文字操作参考：[官方入门手册](https://inkscape-manuals.readthedocs.io/en/latest/text.html)。
