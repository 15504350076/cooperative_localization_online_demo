## 二、怎样核查结果

1. 执行`python3 tools/check_report_results.py`：从统一坐标的全部逐时输出重算84条件、1680次RMSE及分组统计。
2. 执行`python3 tools/check_fusion_review.py`：核对内部坐标旋转/平移不变性、201原点、84项实际转换、默认UWB输出逐点不变、原始输入哈希、原库和V1.3基线、19幅Word图片、13幅新图来源、20项滤波诊断统计、静止秩、12项C++参数统计及六份201坐标CSV。
3. `data/fusion_peak_analysis_20261030/summary.json`保存峰值及全部受控结果，NPZ保存实际曲线；方向/形状分解使用真值只作误差归因，不反馈估计器，不把分解后的低误差当成定位精度。
4. `data/rte_startup_diagnostics_20261030/建系参数对照.csv`列12种配置。后段无有效输出时留空，正式表标注“无有效输出”；不填零、不丢弃该配置。
5. 复现说明列出完整命令、数据和绘图入口。`本轮方法复核验证.json`、`本版结果复算.json`和排版检查文件保存本次实际核对结果。

VIO/LIO采用位移输出层模型，IMU采用测量误差模型；两者都不是现有三盒的动态实测精度。原始图像/点云采集和六组静止实测另在第4章列示。三类数据不混写。
