# V1.4阅读与复现

本目录同名Markdown是正式报告源稿，Word和PDF由其排版。手改源稿后执行下方“只更新格式”命令；build_v14_report.py默认也保留源稿，只有--refresh-content会用生成器重建正文。

## 当前数据与方法

- 正文84个条件、每条件20次，共1680次噪声重复；本版实验条件清单.json列出逐时输出和统计。三类输入各三档，无锚点18条件、五个单锚点位置45条件、额外5/20厘米测距18条件、默认UWB三条件。
- 默认UWB保持原有瞬时队形坐标。传感器分级、锚点布置及RTE原始输出按201当前位置为原点、201本车初始局部轴为固定轴。RTE坐标转换话题以首次有效结果中的201至202方向为固定X轴。第3.3节机动试验也采用201固定轴评价。
- data/single_anchor_outdoor_20261029保存运动与测距输入；data/single_anchor_layout_20261029保存测量驱动初始化和原始融合输出；两目录全部保留。
- data/common_reference_20261030保存统一201轴的84条件输出、summary.json及全部仿真结果.csv。转换使用初始化估计的201局部转角和201同刻估计位置，真值按同一坐标用于评价；原始条件选择.json固定输入清单，避免后续编辑报告影响复算。pose_exports给出六组代表性重复试验1的离线位置CSV。
- 分级运动仿真按扩展卡尔曼滤波的状态和测量更新过程计算：IMU状态包括位置、速度和局部转角，VIO/LIO状态包括位置和局部转角。本轮IMU输入采用三档残余和游走参数；VIO/LIO采用包含滩涂、沙地和训练场退化因素的位移输出条件。
- data/fusion_peak_analysis_20261030保存四档输入的原始重放、去方向漂移、去测距随机项、方向过程方差扩大和90秒建系共20次诊断，复用重复试验1。方向/形状分解用于给出峰值来源，主曲线和精度统计按原始输出计算。
- data/rte_startup_diagnostics_20261030保存三档测距与四种建系配置的12组结果和拒绝原因；其中10米仅作为当前RTE实现的初始化判据，不作为规划运动要求。建系参数对照.csv同时列有效段RMSE及后段RMSE，后段没有有效输出时留空。data/maneuver_observability_20261101保存低、当前、高三种相对机动条件的20次重复结果、几何敏感度和60～300秒位置RMSE。

## 从输入重算

在工程根目录执行；已保存原始输出时可从第三条命令开始。完整重跑会更新对应数据目录，请保留原始归档后进行。

```bash
OPENBLAS_NUM_THREADS=1 python3 tools/evaluate_single_anchor.py --trials 20
OPENBLAS_NUM_THREADS=1 python3 tools/evaluate_anchor_layout.py
OPENBLAS_NUM_THREADS=1 python3 tools/evaluate_common_reference.py
OPENBLAS_NUM_THREADS=1 python3 tools/analyze_fusion_peaks.py
OPENBLAS_NUM_THREADS=1 python3 tools/analyze_fusion_peaks.py --profiles vio_精细 --output data/fusion_peak_vio_precise_20261102
OPENBLAS_NUM_THREADS=1 python3 tools/evaluate_rte_startup_diagnostics.py
OPENBLAS_NUM_THREADS=1 python3 tools/analyze_maneuver_observability.py
OPENBLAS_NUM_THREADS=1 python3 tools/analyze_maneuver_types.py
OPENBLAS_NUM_THREADS=1 python3 tools/analyze_straight_maneuvers.py
OPENBLAS_NUM_THREADS=1 python3 tools/plot_fusion_review.py
python3 tools/check_report_consistency.py
python3 tools/check_report_results.py
python3 tools/check_fusion_review.py
```

RTE诊断重编译需要g++、Eigen和既有build_rte_verify库；--reuse-outputs只重算已经完成的12次输出。正式报告图23采用10秒窗口、5米运动判据的三组RTE对照，读取data/rte_startup_diagnostics_20261030/w10_d5_s*_output.csv及对应真值，由plot_fusion_review.py绘图。较早一组10米判据的原始回放和全部配置对照仍保留在该数据目录。
