# 跨平台默认融合与工程命名实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让同一套 C/C++ 算法源码可分别构建为 Windows DLL 与 RK3588 ARM64 `.so`，默认运行 IMU+测距融合，并以中性工程名和中文 Git 版本完成交付。

**Architecture:** 算法核心和稳定 C ABI 保持平台无关，Windows 临时 UDP Demo 与上交 ROS 2 wrapper 都只作为适配层。默认配置切换到惯性融合，原仅测距配置作为显式兼容模式保留。

**Tech Stack:** C++17、CMake、CTest、Python 3、Windows MSVC、Ubuntu 22.04 GCC、ROS 2 Humble、Git。
