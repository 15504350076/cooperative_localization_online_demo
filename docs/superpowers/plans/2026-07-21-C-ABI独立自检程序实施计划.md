# C ABI独立自检程序实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增一个与生产在线链路完全隔离、通过公开C ABI自动验证三车IMU＋测距已有功能的main程序。

**Architecture:** `self_check.cpp`作为无网络无文件的C ABI消费者，返回结构化结果；薄主函数只负责打印和退出码。单元测试直接调用自检函数，CTest再启动真实可执行文件验证最终交付入口。

**Tech Stack:** C++17、C ABI、CMake、CTest、MSVC/GCC。
