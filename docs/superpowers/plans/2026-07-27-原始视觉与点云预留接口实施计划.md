# 原始视觉与点云预留接口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 增加可映射 ROS 2 原始图像和 PointCloud2、但当前明确不参与算法的稳定 C ABI。

**Architecture:** 公开头声明固定布局元数据和只读缓冲区视图，`c_api.cpp`只在边界执行同步校验并原子写回“已验证但未使用”诊断。接口不依赖 ROS 2、不进入 `Engine`、不扩展 UDP/ZJCL。

**Tech Stack:** C11 ABI、C++17、CMake、CTest、MSVC/GCC。
