# 15维 IMU—UWB 融合实施计划

> 历史实施记录：本文中的旧配置名反映当时执行过程；当前默认配置和文件名以 2026-07-21 实施计划为准。

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有三车 UWB 在线 Demo 中增加标准 ROS 2 IMU 瞬时量驱动的 15 维 ESKF 预测和联合 UWB 更新，同时完整保留 UWB-only 模式。

**Architecture:** 新增独立四元数数学层、单节点 15 维惯性传播层和多节点联合协方差层；`Engine` 通过可选惯性配置在旧 `RangeEkf` 与新融合路径之间分流。C ABI、ZJCL、日志、回放和 Python 模拟器使用新增的版本化 IMU 类型，既有 Range 类型不变。

**Tech Stack:** C++17、CMake 3.16+、现有 `DenseMatrix`、稳定 C ABI、Python 3、UDP/ZJCL/ZJLG、Visual Studio 2022；不新增 Eigen、ROS 2 或 GPL 代码依赖。

**Git约束：** 用户禁止未经允许执行 Git。本计划所有“检查点”只记录文件和测试结果，不执行 `git add`、`git commit`、`git push`、分支或标签命令。

**中文注释规范：** 所有新增公开 C/C++ 结构体、枚举、函数、类和关键成员使用中文 Doxygen 或块注释说明用途、单位、坐标系、所有权和错误语义；15维状态顺序、ENU/FLU变换、中值积分、协方差块传播、UWB雅可比、误差注入与事务回滚必须有中文算法注释。修改既有文件时只在接口边界和不直观逻辑处补充中文注释，不做逐行翻译，不改变英文标识符，避免注释重复代码或很快失效。
