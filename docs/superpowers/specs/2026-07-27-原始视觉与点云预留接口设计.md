# 原始视觉与点云预留接口设计

## 1. 目标

在既有 C ABI 上追加 ROS 2 `sensor_msgs/Image` 与 `sensor_msgs/PointCloud2`
可逐字段映射的只读数据视图。当前版本只验证输入契约并返回“已验证但未使用”，
不复制大块数据、不进入 `Engine`、不改变 IMU＋测距状态，也不加入临时 UDP/ZJCL。

## 2. 接口边界

- 新增 `zju_coop_camera_image_packet_t`，携带节点、相机、序号、统一时间、
  `frame_id`、`encoding`、宽高、行步长以及只读字节缓冲。
- 新增 `zju_coop_point_field_t` 和 `zju_coop_point_cloud_packet_t`，保持
  `PointField` 与 `PointCloud2` 的字段、点步长、行步长、大小端和稠密标志。
- 新增 `zju_coop_raw_input_result_t`，成功时明确返回
  `ZJU_COOP_RAW_INPUT_VALIDATED_NOT_USED`。
- `data`、`fields`及其内容只在函数调用期间借用；函数返回后库不保存任何指针。
- 新接口是 v1 的追加能力，既有结构、函数和枚举数值不改变。

## 3. 校验

两个入口都检查句柄、结构头、保留位、0/1 布尔值、节点号、序号、非零时间、
NUL 结尾帧名、维度、步长、乘法溢出以及缓冲区长度。点云还检查字段数组跨度、
字段名、ROS `PointField` 数据类型、数量和字段末端不超过 `point_step`。

## 4. 状态与错误语义

- ABI或参数错误返回既有 `zju_coop_error_code_t`，调用方结果缓冲保持不变。
- 合法输入返回 `ZJU_COOP_OK`，结果处置为“已验证但未使用”。
- 调用不设置 `processing_started`，因此不会阻止随后配置惯性路径。
- 不生成定位、质量、拓扑或告警，不记录到当前 ZJLG，不跨平台发送原始数据。

## 5. 验证

增加纯 C 头文件冒烟、C ABI 默认值、合法图像/点云、坏布尔、坏字段、坏长度、
输出原子性及“预留输入后仍可配置惯性”测试；最后执行 Release 构建、完整 CTest
和独立自检。
