# 全工程中文注释与使用学习指南设计

## 目标

在不改变算法、协议和运行行为的前提下，为工程内每个程序模块补充中文说明，并形成可直接用于开发、联调和交接的使用方法、学习路线与编写思路。

## 注释层级

1. 每个 C、C++、Python、CMake 和运行配置文件必须包含模块级说明，明确职责、边界及主要依赖。
2. 公共结构体、类和接口说明输入输出、单位、坐标系、时间戳、生命周期及失败语义。
3. 关键处理阶段说明数据如何从接入、校验、时间推进、滤波更新流向结果、日志和网络输出。
4. 关键行只解释容易误改的状态排列、矩阵块、坐标变换、数值门限、协议字节序、CRC、重复包与超时判断。
5. 测试说明验证目标、输入构造和关键断言；不逐行复述测试代码。

## 注释边界

- 不给显而易见的赋值、循环自增和普通函数调用添加无信息注释。
- 不在注释中宣称尚未实测的性能指标。
- 不把临时 UDP 演示协议描述成最终上交接口。
- 不改变现有15维状态定义、IMU瞬时量中值积分、质量降级、动态拓扑和C ABI边界。
- 后续激光雷达、视觉、ROS 2适配和ARM64部署使用扩展点说明，不写入未实现代码。

## 文档交付

新增一份工程使用、学习和编写思路指南，并从 README 建立入口。指南覆盖Windows验证、Ubuntu/RK3588构建、无实物自检、在线仿真、上交ROS 2调用边界、推荐阅读顺序和二次开发步骤。

## 验证与提交

完成后执行Release构建、C ABI自检、CTest和Python语法检查；再核对所有目标文件均有模块说明。现有未提交的独立自检和IMU适配改动一并纳入当前完整版本，以中文提交信息提交，不执行远程推送。
