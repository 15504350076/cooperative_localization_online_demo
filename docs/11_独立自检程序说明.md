# 独立自检程序说明

## 1. 用途

`zju_coop_self_check` 是一个独立 `main` 程序，用来快速确认当前动态库的公开 C ABI 和最小三车算法闭环能否正常工作。它内部构造确定性的静止 IMU 与 3 m、4 m、5 m 三边测距，不读取配置文件，不打开 UDP 端口，不依赖 ROS 2，不访问传感器、日志或系统时钟。

因此，自检不会改变 `zju_coop_online`、`zju_coop_replay`、后续浙大 ROS 2 适配节点或实车配置；它也不能与在线进程共享同一个算法句柄。自检结束后会销毁自己创建的临时句柄。

## 2. 验证内容

程序逐项验证：

1. C ABI 与版本查询；
2. 三车会话创建和 15 维惯性配置；
3. 三个节点 IMU 时间基准建立；
4. 静止 IMU 递推传播；
5. 三条测距更新；
6. 两阶段输出缓冲区查询和主参考坐标输出；
7. Pose2D v2 只读查询中的共同时间、参考节点、`frame_id`、3-4-5 位置和三车 `0°/+90°/-135°` ENU 航向；
8. 兼容 C ABI v1 定位结果继续保持 yaw/z 无效标志；
9. 三车拓扑连通和二维可观；
10. 重复测距包拒绝；
11. 输入停止后的 `LINK_TIMEOUT`；
12. 新测距到达后的网络恢复；
13. 算法句柄销毁。

程序当前记录 14 个独立检查项。全部通过时最后一行为 `SELF_CHECK PASS (passed=14, failed=0)` 且进程退出码为 `0`；任一项失败时退出码为 `1`。

## 3. Windows 运行

```powershell
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build --config Release --target zju_coop_self_check --parallel
build\Release\zju_coop_self_check.exe
```

如已执行安装：

```powershell
install\bin\zju_coop_self_check.exe
```

运行目录必须能找到同版本、同架构的 `zju_coop.dll`。通过 CMake 构建和安装时会自动放置依赖。

## 4. Ubuntu 22.04 / RK3588 运行

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build -j"$(nproc)" --target zju_coop_self_check
./build/zju_coop_self_check
```

安装后运行：

```bash
cmake --install build --prefix install
./install/bin/zju_coop_self_check
```

RK3588 必须在 AArch64 盒端原生构建，或使用正确的 AArch64 sysroot/交叉工具链构建；Windows x64 的 `.exe/.dll` 不能复制到盒端使用。

## 5. 验证边界

自检通过只证明：动态库能够被加载，公开 ABI 调用链有效，当前编译产物能完成一组无噪声确定性 IMU＋测距闭环，能够查询 GCS 所需的三车二维相对位置和各自航向，并且超时/恢复状态行为符合软件约定。

它不证明真实 UWB 精度、IMU 标定质量、时间同步正确性、ROS 2 topic/QoS 映射、网络稳定性、CPU/内存指标或长时间实车可靠性。后续实机联调仍需按 `04_AIBrainBox部署与上交ROS2适配说明.md` 和 `05_联调与验收说明.md` 完成盒端 CTest、浙大 ROS 2 适配节点、真实数据、长稳和精度验证。
