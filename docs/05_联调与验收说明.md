# 联调与验收说明

## 1. 本机在线闭环

默认使用四个进程/终端：GCS、online、模拟器和可选 replay。

Windows Debug 示例：

```powershell
py -3 -B tools\gcs_dashboard.py --udp-port 39002 --http-port 8080
build\Debug\zju_coop_online.exe --config config\demo.ini
py -3 -B tools\imu_uwb_simulator.py --host 127.0.0.1 --port 39001 --duration 10
build\Debug\zju_coop_replay.exe --config config\demo.ini --log logs\cooperative_localization_demo.zjlg --speed 0 --output-mode stream
```

浏览器访问 `http://127.0.0.1:8080`。模拟器使用固定 seed 和 3-4-5 三角形，可用命令行加入噪声、NLOS 和丢包。

## 2. 自动 smoke

```powershell
py -3 -B tools\imu_online_smoke_test.py `
  --online-exe build\Release\zju_coop_online.exe `
  --replay-exe build\Release\zju_coop_replay.exe `
  --config build\config\demo.ini
```

自动测试应验证：

- 收到三个节点的 IMU 和三条观测边；
- 收到 Localization、Network、Observation 和 AlgorithmStatus；
- 停止 Range 超过边超时后收到 ACTIVE Alert；
- 日志非空且包含 Input/Output；
- replay 成功读取并重新输出；
- 子进程非零退出、缺少帧或超时都会使测试失败。

## 3. 真实 UWB 联调前置清单

| 项目 | 责任方 | 进入联调的最低条件 |
|---|---|---|
| A/B/C 与 node_id | 双方 | 唯一且与 UWB 地址映射一致 |
| 外部初值 | 上交 | 三车二维坐标、速度和不确定度可配置 |
| 统一时间轴 | 上交 | 单车/跨车同步完成，stamp 与本地接收时刻可比较 |
| UWB TLV | 上交 | 距离、单位、质量、NLOS、有效标志和序列映射已冻结 |
| ROS 2 wrapper | 上交 | C ABI 串行调用，错误码和处理结果完整记录 |
| 坐标系 | 双方 | x/y 正方向、手性、frame 名称和 epoch 书面冻结 |
| GCS 网关 | 上交 | 结果白名单、版本、错误处理和传输状态已实现 |

## 4. 功能验收场景

### 正常三边

- A 输出在 `(0,0)`；B/C 与外部初值同一坐标分支；
- `yaw_valid=0`、`z_valid=0`；
- 三车可达，网络 connected/observable；
- 结果标称 10 Hz，三边观测标称 20 Hz。

### 单边断开

- 超过 `edge_timeout_ns` 后有效边减少；
- 三车几何不可观时置 `GRAPH_GEOMETRY_DEGENERATE`；
- 网络告警进入 ACTIVE；
- 恢复三边并完成状态机恢复后发一次 CLEARED。

### 时间异常

- `receive_timestamp_ns=0`、过度未来或延迟包被拒绝；
- Network reason 出现 `TIME_SYNC_TIMEOUT`；
- GCS 仅显示算法原因，不尝试修复时间同步。

### 质量退化

- NLOS 比例、有效率或频率越过配置阈值；
- ObservationState 与 FusionAction 按持续时间进入降权、暂缓或拒绝；
- GCS 显示统计和动作，不重新计算门限。

### 协议异常

- 错 magic、版本、长度、CRC、布尔、枚举、reserved 和跨字段关系均被丢弃；
- AlgorithmStatus 的 `protocol_errors` 增长；
- 上一合法 GCS 快照不被非法帧覆盖。

## 5. 性能与精度声明

初版 smoke 只证明软件链路和状态行为，不证明真实 UWB 定位精度、实时性或资源指标。真机验收必须给出轨迹真值或独立测量基准、误差统计方法、测试环境、运行时长及 CPU/内存/磁盘数据后，才能形成性能结论。

## 6. 交付验收证据

每次交付至少保存：

- 配置、编译器和平台信息；
- configure/build/ctest 完整退出码；
- Python unittest 与在线 smoke 结果；
- `zju_coop_version_string()` 与 ABI 值；
- 事件日志和 replay 摘要；
- 未通过项、外部阻塞和复测计划。

不得用口头“能跑”替代命令输出，也不得把 Windows 仿真结果写成 ARM64 真机结果。
