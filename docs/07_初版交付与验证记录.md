# 初版交付与验证记录

记录日期：2026-07-19。本文只报告实际完成并在当前 Windows x64 环境验证的内容；未把 RK3588、ROS 2、真实 UWB 或实车性能写成已完成。

## 1. 文件修改/新增清单

| 文件或目录 | 修改内容 | 原因 |
|---|---|---|
| `CMakeLists.txt`、`cmake/check_elf_exports.cmake` | C++17 动态库、online/replay、示例、测试、安装规则及 Linux 导出检查 | 同时支持 SDK 和可执行程序交付，并为 ARM64 构建保留标准 CMake 路径 |
| `include/zju_coop/c_api.h`、`export.h` | 版本化纯 C ABI、opaque handle、调用方缓冲区、导出宏 | 供上交 ROS 2 wrapper 调用，避免 ROS 2 类型进入核心 |
| `include/zju_coop/types.hpp` | ROS 无关的测距、定位、网络、观测、状态与原因位类型 | 统一算法内部数据语义 |
| `src/core/dense_matrix.*`、`range_ekf.*` | 稠密矩阵和三车联合二维 Range EKF，包含跨节点协方差、预测、NIS 与 Joseph 更新 | 用 UWB 测距完成二维相对状态估计并传播不确定度 |
| `src/core/rigidity.*` | 连通性、可达性和二维刚性秩检查 | 三车只靠距离时必须识别少边、共线和不可观状态 |
| `src/core/degradation_monitor.*` | 观测窗口、NLOS/有效率/频率/残差、降权/暂缓/拒绝/恢复 | 实现方案要求的异常观测处理和退化状态 |
| `src/core/engine.*` | 配置节点/候选边、时间与重复校验、动态拓扑、EKF 调度和输出汇总 | 形成算法最小闭环，且不硬编码有效边数量 |
| `src/api/c_api.cpp` | C ABI 到 C++ Engine 的事务性适配和严格输入/输出校验 | 防止结构版本、stride、容量或非法测距造成部分写入 |
| `src/protocol/crc32.*`、`wire_protocol.*` | ZJCL 1.0 小端帧、CRC、固定 payload 和严格枚举/数值校验 | 为 ROS 2 尚未冻结阶段提供可替换的在线演示协议 |
| `src/protocol/event_log.*` | ZJLG 1.0 Input/Output 事件日志及边界检查 | 支持审计和任务后重新计算式回放 |
| `src/config/ini_config.*`、`config/demo.ini` | 节点初值、滤波、退化、时间、端口、频率、日志与资源上限配置 | 避免在源码中硬编码运行参数 |
| `src/net/udp_socket.*` | Windows/Linux UDP 封装 | 为临时受控网络 demo 提供真实在线收发路径 |
| `src/apps/app_support.*` | C ABI 调用、结果帧编码、AlgorithmStatus/Alert 生命周期 | 复用在线与回放适配语义，并明确后二者不属于 C ABI v1 直接输出 |
| `src/apps/online_main.cpp` | 在线 Range 接收、算法调用、快照/状态/告警输出和日志 | 实现三车在线闭环 |
| `src/apps/replay_main.cpp` | 跳过历史 Output、重新送入 Range、stream/final/none 输出（默认 final）和倒退时间安全处理 | 回放应重算而非复制历史结果，且不得发生时间下溢 |
| `examples/sdk_consumer.cpp` | 可编译的创建、push、两阶段 step、销毁示例 | 给上交提供最小调用模板 |
| `tools/zjcl_protocol.py` | 与 C++ 黄金字节一致的 Python 协议实现 | 支撑模拟器、参考 GCS 和跨语言验证 |
| `tools/uwb_simulator.py` | 3-4-5 三角形三边 UWB 模拟器，含噪声/NLOS/丢包 | 在真实设备未到位时形成可重复在线数据源 |
| `tools/gcs_dashboard.py` | 基础二维点位、网络/观测/算法状态和活动告警参考页面 | 验证结果链路；不是交大生产 GCS 的完整实现 |
| `tools/online_smoke_test.py` | 启动真实进程并验证正常网络、停发后 LINK_TIMEOUT、日志和回放 | 防止仅靠单元测试误报在线闭环完成 |
| `tests/*.cpp`、`tests/c_header_smoke.c`、`tools/test_*.py` | 核心、C ABI、协议、配置、UDP、日志、GCS 和进程辅助测试 | 对正常、边界、损坏、资源上限和回归路径提供证据 |
| `README.md`、`临时UDP演示协议_v1.md`、`docs/01`–`docs/06` | 架构、接口、协议、部署、联调、限制及命令说明 | 为浙大—上交—交大交接提供可执行口径 |

工程外同时新增/修订：`协同定位演示系统/对交大GCS开发的需求.docx` 及其生成器 `文档工具/build_gcs_requirements.py`；历史 v1.0/v1.1/v1.2 文件未删除。
